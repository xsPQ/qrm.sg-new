# Security Rules

Trust Boundaries prüfen; Input validieren, Output encoden, Autorisierung objektbezogen testen, Rechte minimieren, Timeouts/Rate Limits nutzen. Keine Secrets/PII in Repo, Prompt, Logs, Artefakten oder Images.

Pflichtreview bei Auth/Authz, Mandant, PII, Zahlung/Lizenz, Upload/Pfad, Migration, externer API, Secrets und Produktion. Findings: Severity, Asset, Exploitpfad, Evidenz, Fix, Retest.

Critical/High blockieren Release ohne explizite zeitgebundene Risikoakzeptanz.
