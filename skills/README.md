# DevAgency Skills

Skills are reusable procedures; roles define authority and rules define policy.

| Skill | Primary use | Typical roles |
|---|---|---|
| `task-preflight` | readiness/loaded-rules gate | every executing role |
| `git-workflow` | branch/commit/PR/tag | development, docs, release |
| `test-and-verify` | test design/evidence | development, test, QA |
| `code-quality-review` | independent correctness review | Reviewer, QA |
| `security-review` | security gate | Security Reviewer/risk owners |
| `root-cause-debugging` | failure diagnosis | Debugging Specialist |
| `docker-delivery` | container delivery | DevOps Docker Agent |
| `release-readiness` | release/deployment/health | Release Orchestrator |

Install into the Paperclip company skill library and assign by shortname. Verify adapter skill-sync support. A skill grants procedure, never organizational authority.
