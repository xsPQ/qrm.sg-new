# Architecture Decision Records

ADRs dokumentieren schwer rücknehmbare Architektur-/Security-/Betriebsentscheidungen und bewusste Abweichungen von Regeln. Nummeriere fortlaufend, ändere akzeptierte ADRs nicht rückwirkend und ersetze sie durch eine neue ADR mit `supersedes`.

Kleine Implementierungsdetails gehören in Tasks, nicht in ADRs.
