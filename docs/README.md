# DevAgency Documentation

- [company/](company/): Betriebsmodell, Rollen, Ressourcen, Prozess, Status, Routing und Metriken.
- [context/](context/README.md): kurze Fakten über das tatsächliche Repository.
- [planning/](planning/README.md): Artefakte zwischen Pflichtenheft und Development.
- [adr/](adr/README.md): akzeptierte Entscheidungen und Regelabweichungen.

Das ausführliche Soll steht im Pflichtenheft nach [specification-template.md](specification-template.md). Kontextdateien duplizieren es nicht.

| Situation | Dateien |
|---|---|
| neues Projekt | Mission, Operating Model, Specification- und Analysevorlage |
| Task zerlegen | Pflichtenheft, Bedarfsanalyse, Phasenplan, Task-Vorlage |
| Task routen | Task-Review, Routing- und Ressourcenmodell |
| implementieren | AGENTS, Rolle, Task, relevante Context- und Regeldateien |
| QA/Security | Task, Diff, Nachweise, Test-/Security-Regeln |
| Release | Release-Regeln, Checkliste, Rollbackplan |

Eine Aussage hat eine maßgebliche Quelle. Änderungen folgen der Konsistenzmatrix in [TEMPLATE.md](../TEMPLATE.md).
