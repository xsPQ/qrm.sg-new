# Session: Phase Planning

**Agent:** Phase Planner. **Load:** Spec, Bedarf, Risiken, Statusmodell.

Abnehmbare Wertschnitte bilden; Abhängigkeiten, Releases, Rollen, Budget, Verifikation und Security ordnen. Fundament nur soweit benötigt. Keine Implementation.

**Output:** Phasen mit Ziel, Scope, Nicht-Zielen, Deliverables, Acceptance, Risiken, Taskkandidaten. **Gate:** messbar/unblockiert -> `task_decomposition`.
