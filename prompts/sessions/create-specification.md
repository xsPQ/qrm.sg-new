# Session: Create Specification

**Agent:** Spec Architect. **Load:** Idea/Goal, Quellen, Specification Template/Rules.

Problem, Nutzer, Wert, Grenzen und Autoritäten klären. Flows, Daten, Schnittstellen, Requirements, NFR, Security, Betrieb und Acceptance mit IDs schreiben. Fragen mit Owner führen; Traceability aufbauen. Keine Selbstfreigabe.

**Output:** Spec Draft plus Fragen/Risiken. **Gate:** Pflichtkapitel vollständig -> `spec_draft` und Review; sonst Refinement/Blocker.
